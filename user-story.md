# User Story Template

## User story

**As a** <type of user>,
**I need** <some goal>,
**so that** <some reason>.

## Acceptance criteria

### Scenario: <scenario name>
**Given** <an initial context>,
**When** <an action occurs>,
**Then** <an expected outcome>.

## Definition of done

- [ ] Automated tests cover the success case.
- [ ] Automated tests cover relevant error cases.
- [ ] All tests pass.
- [ ] Changes are reviewed and merged into `main`.
